# Kairo Glassmorphism Calculator App

A modern, responsive, glassmorphism-styled calculator web application generated by the **Kairo-AI** software engineering pipeline.

---

## 🌟 Key Features

* **Glassmorphism Design System**: Vibrant background globs, translucent frosted glass cards (`backdrop-filter`), glowing neon accents, and smooth active press micro-animations.
* **Clean Architecture**: Built using a strict Object-Oriented Separation of Concerns:
  * `CalculatorEngine`: Handles arithmetic, floating-point precision rounding, memory registers (`MC`, `MR`, `M+`, `M-`), percentages, square root (`√`), square (`x²`), and negation (`±`).
  * `CalculatorUI`: Handles DOM rendering, theme switching, dynamic font auto-scaling, and keyboard event handlers.
* **Full Keyboard Support**:
  * Digits `0-9`, `.`, operators `+`, `-`, `*`, `/`
  * Calculate: `Enter` or `=`
  * Clear: `Escape` or `c`
  * Backspace: `Backspace`
  * Percentage: `%`
* **Theme Persistence**: Light and Dark mode toggle with `localStorage` preference memory.
* **Responsive Layout**: Fluid flexbox and CSS Grid layout scaling from mobile screens to desktop viewports.
